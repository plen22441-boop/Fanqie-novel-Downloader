# คำสั่งงาน QC — วางเป็น prompt แรก พร้อมแนบไฟล์

> **แนบไฟล์ 3 อย่าง:**
> 1. ไฟล์ตอนที่จะ QC (เช่น ตอน 101–120)
> 2. ไฟล์ตอนชุดถัดไป (เช่น ตอน 121–140) — เพื่อให้อ้างอิงเหตุการณ์ตอนถัดไปได้
> 3. อภิธานศัพท์ (fuya_continuity_glossary)

---

QC บรรณาธิการ ตอน [XXX–YYY]

แนบไฟล์ตอน + ตอนชุดถัดไป + อภิธานศัพท์มาแล้ว

ทำตามขั้นตอนนี้:

1. **อ่านทั้ง 20 ตอน** ให้จบ อ่านท้ายตอนทุกตอนอย่างละเอียด
2. **ให้คะแนน PULL 1–5 ทุกตอน** — จำไว้ว่าต้องพบ PULL ≤ 2 อย่างน้อย 6–10 ตอนจาก 20 ตอน
3. **แก้ทุกตอนที่ PULL ≤ 2:**
   - ลองตัดตอนใหม่ (ย้ายย่อหน้า) ก่อน
   - ถ้าไม่เหมาะ ให้เพิ่มย่อหน้าปิดท้าย 1–3 ประโยค อิงเหตุการณ์จริงในตอนถัดไป
4. **ตรวจเพิ่มเติม:** ลบหมายเหตุผู้เขียน / แก้ !!! ??? / ตรวจชื่อตามอภิธานศัพท์
5. **ส่งมอบ 3 ไฟล์:** ตัวบทแก้แล้ว (.txt) + รายงาน QC (.md) + log (.md)

ลงมือทำเลย ห้ามตอบแค่ตารางสรุป — ต้องส่งไฟล์ตัวบทที่แก้แล้วทั้ง 20 ตอน
