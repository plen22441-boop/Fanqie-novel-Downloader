สถานะแต่ละหน้าในรอบล่าสุด

1) ใส่ข้อมูล

ไฟล์ JSON ที่กด Export จากแผง 📊 ของสคริปต์ MyNovel Insights หรือ CSV ที่มีคอลัมน์ ts,kind,bookId (เวลา) และ/หรือ title,tags,views,rank (หนังสือ) — ประมวลผลในเครื่องคุณทั้งหมด ไม่ส่งข้อมูลไปไหน

หรือวางข้อความ JSON / CSV

2) ตั้งค่าการวิเคราะห์

ช่วงที่ "คาดว่า" คนอ่านเยอะ: ถึง
หมวดที่ใช้ดูแท็ก/เรื่องฮิต:

"ถ่วงน้ำหนัก" = กันไม่ให้เรื่องดังเรื่องเดียวที่คอมเมนต์ถล่มมาบิดภาพรวมของทั้งเว็บ (แนะนำให้เปิดเมื่อมีคำเตือน)

3) แผนที่ความร้อน: วัน × ชั่วโมง (เวลาไทย)

สีเข้ม = กิจกรรมผู้อ่านมาก (นับจากเวลาคอมเมนต์/ไลก์ ซึ่งเป็น ตัวแทน ของการอ่าน ไม่ใช่ยอดอ่านจริง)

ดูเป็นตาราง

4) คาดไว้ vs เกิดจริง — รายชั่วโมง

ความสูง = เท่าของค่าเฉลี่ย (1.0× = ชั่วโมงธรรมดา) · เส้น/แถบส้มด้านบน = ช่วงที่คุณคาดไว้

5) ช่องว่าง: คนอ่าน vs คนลงตอน

ฟ้า (ขึ้น) = สัดส่วนผู้อ่านมากกว่าสัดส่วนตอนที่ลง → แข่งน้อย น่าลงตอน · แดง (ลง) = ตอนใหม่แย่งกันเยอะเกินผู้อ่าน

🔥 เรื่องที่คนอ่านเยอะ

วิวพุ่ง = ยอดวิวที่เพิ่มใน 24 ชม.ล่าสุด (ถ้าเก็บมาไม่ถึง 24 ชม. ใช้เท่าที่มี) · ยอดวิวรวม = ยอดสะสมทั้งหมด (เรื่องเก่าได้เปรียบ)

วิวพุ่งที่สุด

    ยอดวิวรวมสูงสุด

      6) แท็ก / แนวที่ติดอันดับ

      คะแนนอันดับ = รวมน้ำหนักตามตำแหน่ง (อันดับ 1 ได้มากสุด) · โอกาส = ส่วนแบ่งในอันดับ ÷ ส่วนแบ่งในจำนวนเรื่องทั้งหมด (>1× = ติดอันดับเกินจำนวนคู่แข่ง) · วิวพุ่ง/เรื่อง = วิวที่เพิ่มเฉลี่ยต่อเรื่องในแท็กนั้น (แท็กไหนดึงคนอ่านได้จริง) · คลิกหัวตารางเพื่อเรียง

      แท็กที่มักมาคู่กัน

      7) ข้อเสนอแนะจากข้อมูลชุดนี้

        ข้อเสนอแนะสร้างอัตโนมัติจากตัวเลขด้านบน ควรทดลองจริง (เช่น ลงตอนสลับ 2 ช่วงเวลา 2–4 สัปดาห์ แล้วเทียบยอดอ่าน 24 ชม.แรกในหลังบ้านนักเขียน) ก่อนเชื่อเต็มที่

        วิธีใช้ & ข้อจำกัด (อ่านก่อนตีความ)

        2. เปิด MyNovel ตามปกติ แล้วกดปุ่ม 📊 มุมขวาล่าง — ดูเวลาทอง วิวพุ่ง แท็กฮิต ได้ทันที (เปิดแท็บทิ้งไว้ สคริปต์เก็บเองทุก ~1 ชม.)
        3. อยากดูละเอียด: กด Export ไฟล์ ในแผง → กลับมาหน้านี้ แล้วเลือกไฟล์
        • คอมเมนต์ ≠ การอ่าน: คนเงียบอ่านไม่คอมเมนต์ และคนคอมเมนต์มักเป็นแฟนเหนียวแน่น รูปแบบเวลาจึงเป็น "ตัวแทน" ที่อาจเอียง
        • ข้อมูลยอดอ่านรายชั่วโมงจริงมีแค่ในหลังบ้านนักเขียน/แพลตฟอร์ม ถ้าคุณมีสถิติหลังบ้าน ให้ใส่ CSV ts,kind=view จะแม่นกว่ามาก
        • หน้าอันดับเป็นภาพ ณ เวลาที่เปิดดู — ควรเก็บหลายวันเพื่อเลี่ยงอันดับชั่วคราว
        • เวลาทั้งหมดแสดงเป็นเวลาไทย (UTC+7) · เวลาที่รู้แค่วัน ("3 วันที่แล้ว") ไม่ถูกใช้ในกราฟรายชั่วโมง
        • ใช้ข้อมูลเพื่อวิเคราะห์ส่วนตัว และเคารพข้อกำหนดการใช้งานของเว็บไซต์
