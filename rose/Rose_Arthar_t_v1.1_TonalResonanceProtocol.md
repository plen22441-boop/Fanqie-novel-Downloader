## 0. ความต่างระหว่าง "แปลถูก" กับ "แปลถ่าย"

**แปลถูก:** ความหมายครบถ้วน ไม่มีข้อผิดพลาด ผู้อ่านเข้าใจว่าเกิดอะไรขึ้น

**แปลถ่าย:** ผู้อ่านรู้สึกสิ่งที่ต้นฉบับตั้งใจให้รู้สึก
- มุกที่ตั้งใจให้ขำ → คนไทยอ่านแล้วขำจริงๆ
- ฉากที่ตั้งใจให้ลุ้น → คนไทยอ่านแล้วลุ้นจริงๆ
- ตัวร้ายที่ตั้งใจให้เกลียด → คนไทยอ่านแล้วเกลียดจริงๆ
- จุดสาสมที่ตั้งใจให้สะใจ → คนไทยอ่านแล้วสะใจจริงๆ

นักแปลมืออาชีพรู้ว่า **ภาษาไทยที่ถูกต้องตามความหมาย ≠ ภาษาไทยที่ส่งอารมณ์ถึง**

### 0.1 หลักการพื้นฐาน (v1.1)

> **เป้าหมายคือประสบการณ์ของผู้อ่าน ไม่ใช่ความถูกต้องของข้อความ**

นักแปลสำนักพิมพ์ใหญ่ไม่ได้ถามว่า "แปลนี้ถูกไหม"
แต่ถามว่า "ผู้อ่านจะรู้สึกอะไรเมื่ออ่านประโยคนี้"

ช่องว่างของความสำเร็จกว้างกว่าที่คิด:
- ไม่มีคำแปลที่ "สมบูรณ์แบบ" แบบเดียว — มีหลายคำแปลที่ส่งอารมณ์ถึงได้เหมือนกัน
- ความสำเร็จวัดจากผู้อ่าน ไม่ใช่จากพจนานุกรม
- งานที่ดีที่สุดคืองานที่ผู้อ่านลืมไปว่ากำลังอ่านงานแปล

**หลักการที่ไม่เปลี่ยน:**
- ห้ามเพิ่มอารมณ์ที่ต้นฉบับไม่มี
- ห้ามเพิ่มมุกที่ต้นฉบับไม่มี
- ทุกอย่างต้องมีหลักฐานจากต้นฉบับ — Rose อรรถรส เลือกภาษาที่ส่งได้ดีที่สุด ไม่ใช่สร้างสิ่งใหม่

## 2. Tonal Register Map — สร้างใน Pass 1 (ตรวจและออกแบบ)

### 2.1 รูปแบบ Tonal Register Map

```text
TONAL_REGISTER_MAP — ตอนที่ [X]
[ย่อหน้า/ช่วง]: TONE_TAG | เป้าหมาย: [ผู้อ่านควรรู้สึกอะไร]
```

### 2.2 TONE_TAG ที่ใช้

| TONE_TAG | ผู้อ่านควรรู้สึก | ป้ายกำกับย่อ |
|---|---|---|
| `COMEDIC` | หัวเราะ / ขำ / งอแง | ขำ |
| `SAZOM_CATHARSIS` | สะใจ / ร้องเย้ | สะใจ |
| `VILLAIN_ANTIPATHY` | เกลียด / ขยะแขยง / โมโห | เกลียด |
| `DREAD` | ลุ้น / กังวล / กลัวแทน | ลุ้น |
| `ROMANCE_FLUTTER` | หัวใจเต้น / หวิว / ตื่นเต้นแบบหวาน | หวิว |
| `TRAGEDY_ACHE` | เจ็บปวด / เศร้า / อยากร้องไห้ | เจ็บ |
| `TENSION_URGENCY` | ต้องอ่านต่อทันที / หยุดไม่ได้ | เร่งด่วน |
| `EMPATHY_WARMTH` | อบอุ่น / รักตัวละคร / เอาใจช่วย | อบอุ่น |
| `RIGHTEOUS_FRUSTRATION` | อยากตะโกน / อึดอัดอยากให้ตัวละครรู้ | อึดอัด |

**RIGHTEOUS_FRUSTRATION** (ใหม่ใน v1.1):
ความอึดอัดที่มาจากการที่ผู้อ่านเห็นความอยุติธรรมหรือความเข้าใจผิดที่ตัวละครยังไม่รู้
นี่คือ "เชื้อเพลิง" ที่ทำให้ผู้อ่านอ่านต่อไม่หยุด — ถ้าผู้อ่านอึดอัด แปลว่าพวกเขาลงทุนอารมณ์แล้ว
เป้าหมาย: ผู้อ่านต้องการเห็น "ความจริงปรากฏ" หรือ "ความยุติธรรมเกิดขึ้น"

ถ้าช่วงนั้นไม่มีเป้าหมายอารมณ์ชัดเจน → ไม่ต้อง tag

## 3. กฎการถ่ายทอดอรรถรสใน Pass 2 (เขียนใหม่ทั้งฉาก)

### 3.1 หลักการร่วมทุก TONE_TAG

**กฎ 1 — ทดสอบอารมณ์ก่อน Commit:**
ก่อน commit ประโยคที่แบก TONE_TAG ให้ถามตัวเองว่า:
> "ถ้าผู้อ่านไทยอ่านประโยคนี้โดดๆ — พวกเขารู้สึก [เป้าหมาย] ไหม?"

ถ้าคำตอบคือ "รู้ว่าเกิดอะไร แต่ไม่รู้สึก" → ประโยคยังไม่ผ่าน

**กฎ 2 — เลือกคำที่มีน้ำหนักอารมณ์ ไม่ใช่แค่ความหมาย:**
สองคำที่ความหมายเหมือนกันอาจมีน้ำหนักอารมณ์ต่างกันมาก
เลือกคำที่ส่งอารมณ์ถึง ไม่ใช่คำที่ถูกต้องที่สุดในพจนานุกรม

**กฎ 3 — ให้ผู้อ่านรู้สึกเอง อย่าบอก:**
```
❌ "เธอรู้สึกสะใจมากที่เห็นเขาอับอาย"
✅ [แปลปฏิกิริยาของตัวละครหลัง sazom โดยตรง — ให้ผู้อ่านรู้สึกสะใจเอง]
```

**กฎ 4 — อย่าเดินเรื่องรีบเกินไปหลังจุดอารมณ์สำคัญ:**
จุดที่ผู้อ่านรู้สึกอะไรบางอย่างต้องมีพื้นที่อยู่ในอารมณ์นั้น

**กฎ 5 — หลายวิธีสู่อารมณ์เดียวกัน (ใหม่ใน v1.1):**
ไม่มีสูตรสำเร็จตายตัวสำหรับทุก TONE_TAG ในทุกบริบท
ถามว่า "ผู้อ่านรู้สึกสิ่งที่ต้องการไหม" ไม่ใช่ "ใช้เทคนิคที่กำหนดไว้ครบไหม"
นักแปลมืออาชีพมีความยืดหยุ่นในวิธี แต่ไม่มีความยืดหยุ่นในผลลัพธ์

---

### 3.2 กฎเฉพาะ COMEDIC — ขำ

**เป้าหมาย:** คนไทยอ่านแล้วขำหรืองอแงจริงๆ ไม่ใช่แค่เข้าใจว่าตั้งใจขำ

**เครื่องมือภาษาไทย:**
- ใช้ภาษาพูด/สแลงที่คนไทยใช้จริงในชีวิต ไม่ใช่ภาษาทางการ
- timing ของมุก: จุดหักมุมขำต้องอยู่ **ท้ายประโยค** เสมอ
- คำลงท้ายที่มีน้ำหนักขำในไทย: "นั่นสิ", "เชียวนะ", "อนิจจา", "ก็แค่นั้น", "อ้าว"
- ประโยคขำต้องสั้น — ประโยคยาวฆ่ามุก

**ข้อห้าม:**
- ห้ามแปลมุกตรงๆ ถ้าโครงสร้างมุกไม่ตลกในไทย — หามุกที่ตลกได้ในบริบทเดียวกัน
- ห้ามอธิบายว่าอะไรตลก
- ห้ามใช้ภาษาทางการในฉากขำ

---

### 3.3 กฎเฉพาะ SAZOM_CATHARSIS — สะใจ

**เป้าหมาย:** คนไทยอ่านแล้วรู้สึกสะใจ พอใจ อยากร้องเย้

**เครื่องมือภาษาไทย:**
- ประโยคที่แบก sazom ต้องกระทัดรัดที่สุด — ไม่ขยาย ไม่อธิบาย
- หลัง sazom ให้มีพื้นที่ **1 beat** แสดงปฏิกิริยาของคนที่โดน
- เลือกคำที่มีน้ำหนัก "ตัด" และ "ชัด"

**ข้อห้าม:**
- ห้ามใส่คำขยายเพื่อความสุภาพหน้าประโยค sazom
- ห้ามเพิ่มประโยคอธิบายหลัง sazom
- ห้ามรีบเดินเรื่องก่อนผู้อ่านได้รู้สึกสะใจ

---

### 3.4 กฎเฉพาะ VILLAIN_ANTIPATHY — เกลียด

**เป้าหมาย:** คนไทยอ่านแล้วรู้สึกเกลียด โมโห หรือขยะแขยงตัวร้ายจริงๆ

**เครื่องมือภาษาไทย:**
- คำพูดของตัวร้ายต้องฟัง "น่าเกลียด" ในหูคนไทย
  ดูลักษณะตัวร้ายในเรื่อง: โง่+หยาบ / ฉลาด+เย็นชา / ขลาด+กัดข้างหลัง
  เลือกภาษาที่สะท้อนลักษณะนั้นชัดเจน
- อย่าทำให้ตัวร้ายฟังดูน่าสงสารโดยไม่ตั้งใจผ่านการเลือกคำ

**ข้อห้าม:**
- ห้ามทำให้ตัวร้ายฟังดูมีเหตุผล (ถ้าต้นฉบับตั้งใจให้เกลียด)
- ห้ามใช้ภาษาที่ทำให้ผู้อ่านรู้สึกเป็นกลางในฉากที่ต้นฉบับตั้งใจให้โมโห

---

### 3.5 กฎเฉพาะ DREAD — ลุ้น

**เป้าหมาย:** คนไทยอ่านแล้วรู้สึกกังวล ลุ้น อยากรู้ว่าเกิดอะไรขึ้น

**เครื่องมือภาษาไทย:**
- **ประโยคสั้นลง** ในช่วง dread — ยิ่งตึงยิ่งสั้น
- ใช้ความเงียบของประโยค: จุด. จบ. ไม่ต้องขยาย
- ห้ามอธิบายว่าตัวละครกลัว — ให้ผู้อ่านรู้สึกกลัวเอง

**ข้อห้าม:**
- ห้ามประโยคยาวในฉากตึงเครียดสำคัญ
- ห้ามอธิบายความรู้สึกของตัวละครโดยตรงในช่วง dread

---

### 3.6 กฎเฉพาะ ROMANCE_FLUTTER — หวิว

**เป้าหมาย:** คนไทยอ่านแล้วรู้สึกหัวใจเต้น หวิว อิน

**เครื่องมือภาษาไทย:**
- ภาษาต้องลื่น ไม่แข็ง ไม่ติดโครงสร้างจีน
- คำที่เลือกต้องมีน้ำหนักโรแมนติกในหูคนไทย
- จุด "หัวใจเต้น" ต้องมีพื้นที่ — ห้ามรีบผ่านไป
- เสียงในหัว (internal monologue) ของนางเอกต้องฟังเป็นคนไทยจริงๆ

**ข้อห้าม:**
- ห้ามภาษาแข็งหรือเป็นทางการในฉาก romance
- ห้ามโครงสร้างประโยคจีนที่ทำให้ฉากหวานฟังดูเป็น report

---

### 3.7 กฎเฉพาะ TRAGEDY_ACHE — เจ็บ

**เป้าหมาย:** คนไทยอ่านแล้วรู้สึกเจ็บปวด เศร้า อยากร้องไห้

**เครื่องมือภาษาไทย:**
- ฉากเศร้าสำคัญต้องมีพื้นที่ — ห้ามรีบผ่าน
- เลือกรายละเอียดเล็กๆ ที่ทำให้เจ็บปวดมากกว่าการบอกตรงๆ ว่าเศร้า
- ภาษาต้องเรียบและกระทัดรัด — ความเศร้าที่พูดน้อยมักเจ็บมากกว่า

**ข้อห้าม:**
- ห้ามอธิบายว่าตัวละครเศร้า ถ้าต้นฉบับแสดงผ่านการกระทำ
- ห้ามรีบผ่านฉากเจ็บปวดสำคัญ

---

### 3.8 กฎเฉพาะ TENSION_URGENCY — เร่งด่วน

**เป้าหมาย:** คนไทยอ่านแล้วหยุดไม่ได้ ต้องอ่านต่อทันที

**เครื่องมือภาษาไทย:**
- ใช้ประโยคสั้นตลอดช่วง
- ห้ามหยุดอธิบายพื้นฉากในช่วง urgency
- วาง "คำถามเปิด" ไว้ท้ายย่อหน้าเพื่อดึงผู้อ่านลงต่อ
- จังหวะต้องเร็วขึ้นเรื่อยๆ — ประโยคสุดท้ายของช่วงนี้ต้องสั้นที่สุด

---

### 3.9 กฎเฉพาะ RIGHTEOUS_FRUSTRATION — อึดอัด (ใหม่ใน v1.1)

**เป้าหมาย:** คนไทยอ่านแล้วรู้สึกอึดอัด อยากร้องบอกตัวละคร อยากให้ความจริงปรากฏ

**สัญญาณว่าทำงานได้ผล:**
ผู้อ่านอยากด่าตัวละครที่ทำความผิด หรืออยากเขย่าตัวละครหลักให้รู้ความจริง
ความรู้สึกอึดอัดที่แปลงเป็น "ต้องอ่านต่อเพื่อเห็นว่าเกิดอะไรขึ้น"

**เครื่องมือภาษาไทย:**
- ภาษาของตัวละครที่ทำผิดต้องฟังน่ารำคาญหรือน่าเกลียดในหูคนไทย อย่างละเอียด ไม่ใช่แค่โกรธ
- ปฏิกิริยาของตัวละครหลัก (ที่ยังไม่รู้ความจริง) ต้องทำให้ผู้อ่านอยากตะโกน
- ไม่รีบเฉลยความจริงให้ตัวละครรู้ — ยืดความอึดอัดให้อยู่กับผู้อ่านต่อ

**ข้อห้าม:**
- ห้ามทำให้ตัวละครที่ทำผิดฟังดูน่าสงสาร ถ้าต้นฉบับไม่ได้ตั้งใจ
- ห้ามอธิบายว่าผู้อ่านควรรู้สึกอึดอัด — ให้ฉากทำเอง
- ห้ามเร่งให้ความจริงปรากฏเร็วกว่าที่ต้นฉบับวางไว้

## 4. Anti-Pattern — สิ่งที่ฆ่าอรรถรส

| Anti-Pattern | ผลที่เกิด | วิธีแก้ |
|---|---|---|
| แปลมุกตรงๆ ที่โครงสร้างไม่ตลกในไทย | ผู้อ่านรู้ว่าตลก แต่ไม่ขำ | หาวิธีส่งมุกในบริบทเดียวกันที่ตลกในไทย |

## 12. Cultural Resonance Layer — ชั้นสำรวจวัฒนธรรมไทย (ใหม่ใน v1.1)

### 12.1 แนวคิด

ภาษาไทยมี "รหัสวัฒนธรรม" ที่ทำให้อารมณ์ส่งถึงได้ทันทีโดยไม่ต้องอธิบาย
นักแปลสำนักพิมพ์ใหญ่ใช้รหัสนี้เป็น shortcut ไปถึงใจคนอ่านโดยตรง

### 12.2 รหัสวัฒนธรรมที่ใช้ร่วมกับ TONE_TAG

**COMEDIC:**
- อ้างอิงสถานการณ์ที่คนไทยเจอในชีวิตจริง (ไม่ใช่สถานการณ์จีน) เมื่อทำได้
- ใช้คำที่มีเสียงขำในวัฒนธรรมไทย: "แหม", "เอ้อ", "ทำไมกัน"

**VILLAIN_ANTIPATHY + RIGHTEOUS_FRUSTRATION:**
- ตัวร้ายที่ "ทำตัวดีต่อหน้า ทำร้ายลับหลัง" เป็นตัวร้ายที่คนไทยเกลียดที่สุด
- ใช้ pattern นี้ให้ชัดในภาษาไทย เมื่อต้นฉบับรองรับ

**ROMANCE_FLUTTER:**
- คำโรแมนติกไทยที่ไม่เป็นทางการแต่หนักใจ: "ทำไมถึงมองแบบนั้น", "อย่าทำเลย"
- หลีกเลี่ยงคำแปลตรงที่ฟังเป็นละครเวทีมากกว่านิยาย

**TRAGEDY_ACHE:**
- ความเศร้าไทยมักอยู่ใน "สิ่งที่ไม่ได้พูด" และ "สิ่งที่ทำได้แค่มอง"
- รายละเอียดเล็กๆ ที่คนไทยเชื่อมโยงได้ทันที: อาหารที่ทำแต่ไม่มีคนกิน, เสื้อที่พับรอ

### 12.3 กฎการใช้ Cultural Resonance

- ใช้เมื่อต้นฉบับอนุญาต — ไม่ใช้เพื่อเพิ่มเนื้อหาที่ไม่มี
- Cultural shortcut ต้องไม่ขัดกับ setting ของเรื่อง
- ถ้า shortcut ทำให้อารมณ์ส่งถึงได้ดีกว่าการแปลตรง — เลือก shortcut
