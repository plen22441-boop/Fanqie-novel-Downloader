## 1. SCENE_GAZE_AUDIT — ตรวจเลนส์การมอง ไม่ใช่แค่สรรพนาม

### หลักการ
Male Gaze Residue ไม่ได้อยู่แค่ที่คำว่า "เขา/นาย" — มันอยู่ที่ **วิธีที่ฉากถูกสร้างขึ้น** แม้นางเอกจะถูกเขียนเป็นหญิงครบถ้วนแล้วก็ตาม

### สัญญาณ MALE_GAZE_RESIDUE ที่ต้องตรวจ

| สัญญาณ | ตัวอย่างต้นฉบับ | ทิศทางแก้ |
|---|---|---|
| บรรยายรูปร่างผู้หญิงในฉากก่อนนิสัย/บทบาท | "หญิงสาวรูปงามยืนอยู่หน้าประตู…" | เปิดด้วยการกระทำหรือสถานะก่อน รูปลักษณ์มาทีหลังถ้าจำเป็น |
| นางเอกถูกมองจากภายนอกตลอด ไม่มีมุมมองภายใน | บรรยายว่าคนอื่นมองนางเอกอย่างไร | ให้นางเอกมีการรับรู้ตัวเองและมองโลก ไม่ใช่แค่ถูกมอง |
| ออร่า/พลังของนางเอกถูกบรรยายแบบ "บีบ/กด" แบบผู้ชาย | "ออร่าที่ทำให้ผู้คนหยุดหายใจ" | ปรับเป็นความสังเกตที่เฉียบ / การมีอยู่ที่คนอื่นอ่านไม่ออก |
| ฉากต่อสู้เน้นความโดดเดี่ยวกล้าหาญแบบ lone wolf | "ฉันไม่ต้องการใคร" + สู้คนเดียวจนชนะ | นางเอกสามารถสู้คนเดียวได้ แต่ texture ของฉากให้มีการอ่านสถานการณ์และเลือกจังหวะ |
| ฉากที่ผู้หญิงในฉากถูก define ด้วยความสัมพันธ์กับผู้ชาย | "ภรรยาของขุนนางผู้ยิ่งใหญ่" | ให้ตัวละครหญิงรองมีบทบาท/ฐานะของตัวเองก่อน |

### คำถาม SCENE_GAZE_AUDIT (ตรวจทุกฉากที่มีตัวเอก)

```
SCENE_GAZE_AUDIT:
□ ฉากนี้ถูกเล่าผ่านสายตาของใคร? → ต้องผ่านสายตา/ความรู้สึก/การรับรู้ของนางเอก
□ ผู้หญิงในฉากนี้ถูก define ด้วยรูปลักษณ์หรือบทบาทของตัวเองก่อน?
□ นางเอกมีมุมมองภายใน (คิด/รับรู้) หรือถูกบรรยายจากภายนอกอย่างเดียว?
□ พลังงาน/ออร่าของนางเอกถูกบรรยายด้วย texture ที่เหมาะกับตัวละครและยุค?
□ ถ้าเอาชื่อออก — ฉากนี้อ่านรู้ว่าตัวเอกเป็นหญิงจากการสร้างฉาก ไม่ใช่แค่คำสรรพนาม?
```

**ถ้าตอบ "ไม่" ข้อใดข้อหนึ่ง → GAZE_LOCK_BLOCKED — แก้ก่อนส่ง**

## 2. RELATIONSHIP_GENDER_REMAP — แมปความสัมพันธ์ทั้งก้อน (Pass 1 บังคับ)

### หลักการ
เมื่อตัวเอกเปลี่ยนเพศ ความสัมพันธ์ไม่ได้แค่ "romance → friendship" — **โครงสร้างอำนาจและบริบทสังคมของความสัมพันธ์ทุกเส้นต้องถูกตรวจใหม่**

### ตารางแมปบังคับ (สร้างใน Pass 1 ก่อนเขียน batch แรก)

```
RELATIONSHIP_GENDER_REMAP:
ชื่อตัวละคร | ความสัมพันธ์ต้นฉบับ | ประเภท | สถานะหลัง Remap | หมายเหตุ
```

### ประเภทความสัมพันธ์และทิศทาง Remap

| ประเภทต้นฉบับ | รหัส | ทิศทาง Remap |
|---|---|---|
| พี่น้องร่วมสาบาน (結拜兄弟) | SWORN_BROTHER | → พันธมิตรเสมอกัน / สหายไม่ผูกเพศ / พี่น้องสาบานไม่ระบุเพศ (ขึ้นอยู่กับยุคและสำนัก) |
| คู่แข่งชาย vs ชาย | RIVAL_MALE | → คู่แข่งที่มีพลวัต — มักมีการประเมินต่ำก่อน แล้วถูกพิสูจน์ ต้องตรวจว่า rival ยอมรับนางเอกอย่างไร |
| อาจารย์รับศิษย์ (ชาย → ชาย) | MENTOR | → ตรวจว่าสำนัก/ยุครับลูกศิษย์หญิงหรือไม่ ถ้าไม่รับ → นางเอกอาจปลอมตัว / รับไปแล้วเพราะไม่รู้ / เป็นข้อยกเว้น |
| ฮาเร็ม / ผู้ติดตามรัก | HAREM | → เครือข่าย loyalty — แต่ texture ต้องต่าง: ไม่ใช่ความสัมพันธ์เชิงรัก แต่เป็น trust ที่สร้างจากการกระทำจริง |
| พี่/เพื่อนชายที่ปกป้อง | PROTECTOR | → ตรวจทิศ: นางเอกยังยอมถูกปกป้องอยู่หรือเปล่า? ถ้าไม่สมเหตุสมผล → ปรับเป็นความร่วมมือเท่าเทียม |
| ศัตรูที่นับถือ | RESPECTED_ENEMY | → คงได้ แต่ตรวจว่า ศัตรูนับถือด้วยเหตุผลอะไร — ถ้าเป็นเพราะ "ความแข็งแกร่งแบบชาย" ต้องปรับ basis |
| เพื่อนในวัยเด็ก | CHILDHOOD_FRIEND | → ตรวจว่าความสัมพันธ์นี้ยังสมเหตุสมผลในบริบทยุคสมัยหรือไม่ (เด็กหญิง-ชายเล่นด้วยกันได้ในบางยุค) |

### กฎ RELATIONSHIP_REMAP
- สร้าง RELATIONSHIP_GENDER_REMAP table ก่อน batch แรกทุกครั้ง
- ทุกความสัมพันธ์ที่เปลี่ยนต้องมีเหตุผลในโลกของเรื่อง ไม่ใช่แค่ "ระบบบอก"
- ห้ามลบความสัมพันธ์สำคัญออกโดยไม่มีทางเลือกทดแทน
- ถ้า remap แล้วขัดกับ plot จุดใด → REMAP_CONFLICT — รายงานก่อนเขียน

## 3. COOL_CALIBRATION — ปรับ Texture ฉากเจ๋งให้สมเหตุสมผลในโลกที่นางเอกอยู่

### หลักการ
นางเอกสามารถเจ๋งได้เต็มที่เท่าพระเอก — แต่ **วิธีที่ฉากแสดงความเจ๋งนั้นต้องสมเหตุสมผลกับโลกที่นางเอกอยู่** ไม่ใช่เพราะเพศ แต่เพราะ social logic และ strategic logic ของตัวละคร

### ประเภทฉากเจ๋งในต้นฉบับชาย และ Calibration

| ฉากเจ๋งต้นฉบับ | รหัส | Calibration สำหรับนางเอก |
|---|---|---|
| Face-slap สาธารณะ โจ่งแจ้ง | PUBLIC_FACE_SLAP | คงได้ถ้ามีเหตุผล — แต่ตรวจว่าบริบทยุคอนุญาตให้หญิงทำแบบนี้ได้หรือไม่ / ถ้าไม่ → นางเอกอาจทำด้วยวิธีที่ทรงพลังกว่าในโลกนั้น เช่น การพิสูจน์ที่ทำให้คนอื่นหันมาตำหนิฝ่ายตรงข้ามเอง |
| แสดงพลังโจ่งแจ้งให้ทุกคนยอม | POWER_DISPLAY | ได้ — แต่ตรวจว่า นางเอกเลือกเวลาและเป้าหมายหรือเปล่า ฉากที่แสดงพลังแบบ "ปล่อยให้คนอื่นเผยตัวก่อนแล้วค่อยพลิก" มักทรงพลังกว่าในเชิง narrative |
| คนทั้งห้องหยุดหายใจเพราะตัวเอกเดินเข้ามา | PRESENCE_SCENE | ได้ — แต่ texture ที่ใช้: ความเงียบที่เฉียบ / การที่คนอ่านไม่ออกว่านางเอกคิดอะไร / ไม่ใช่แค่ "ออร่าบีบ" แบบผู้ชาย |
| ต่อสู้คนเดียวจนชนะทั้งกองทัพ | LONE_BATTLE | ได้ถ้า power level รองรับ — แต่ตรวจว่า texture ของฉากให้นางเอกมี strategy ไม่ใช่แค่ raw power เพราะ strategy สมเหตุสมผลกับตัวละครที่ต้องคิดก้าวที่สามในโลกที่มีอคติต่อเธอ |
| ดูถูกแล้วพิสูจน์ตัว | UNDERESTIMATED | นี่คือ default ที่ทรงพลังที่สุดสำหรับนางเอก — คงไว้ และให้ payoff ชัดเจน |

### คำถาม COOL_CALIBRATION (ตรวจทุกฉาก "จุดพีค")

```
COOL_CALIBRATION_CHECK:
□ ฉากนี้เจ๋งด้วยวิธีอะไร? → ระบุ type จากตารางข้างต้น
□ บริบทยุค/สังคมในเรื่องอนุญาตให้นางเอกทำแบบนี้ได้หรือไม่?
□ ถ้าทำโจ่งแจ้งไม่ได้ — มีวิธีที่ทรงพลังกว่าในโลกนั้นไหม?
□ ผลลัพธ์ของฉาก (ผู้คนยอมรับ / ศัตรูถูกพิสูจน์) ยังครบอยู่หรือเปล่า?
□ Cool ลดลงหรือเพิ่มขึ้น หลัง calibration?
```

**กฎ: ห้าม calibrate แล้วทำให้นางเอกเจ๋งน้อยลง — ถ้า texture เปลี่ยน ผลลัพธ์ต้องเท่าหรือดีกว่าเดิม**

## 4. INNER_VOICE_REMAP — สร้างตรรกะการคิดของนางเอกใหม่ ไม่ใช่แค่แปลงคำ

### หลักการ
Internal Monologue ของพระเอกชายในนิยายจีนมักมี pattern เหล่านี้:
- คิดเรื่องศักดิ์ศรีและการรักษาหน้า
- คิดเรื่องการครอง power ทางตรง ("ข้าจะทำลายเจ้า")
- คิดเรื่องการกดข่มและความเหนือกว่า
- ประเมินสถานการณ์ด้วยมุมมอง "ข้าต้องชนะ"

สิ่งเหล่านี้ไม่ใช่ปัญหาเรื่องเพศโดยตรง แต่เป็น **residue ของ character template ชาย** ที่ถูก copy มาโดยไม่ได้ rebuild

### INNER_VOICE ที่ต้อง Remap

| Pattern ต้นฉบับ | รหัส | Remap สำหรับนางเอก |
|---|---|---|
| "ข้าจะไม่ยอมให้ใครดูถูก" (ศักดิ์ศรีแบบ masculine honor) | MASCULINE_HONOR | → "รู้ว่าเขาคิดอะไร — ปล่อยให้คิดไปก่อน" / ตรรกะเชิงกลยุทธ์มากกว่าอารมณ์ |
| "ข้าจะครองทุกอย่าง" (conquest mindset) | CONQUEST | → เป้าหมายยังได้ แต่ framing เป็น "ข้าต้องอยู่รอดและสร้างสิ่งนี้ขึ้นมาเอง" |
| "ไม่มีใครเทียบข้าได้" (arrogance แบบประกาศ) | DECLARED_ARROGANCE | → ความมั่นใจเงียบ — รู้ตัวเองดีกว่าที่ใครจะบอกได้ ไม่จำเป็นต้องประกาศ |
| "เจ้าทำให้ข้าต้องฆ่าเจ้า" (direct threat) | DIRECT_THREAT | → ได้ถ้าตัวละครเป็นแบบนั้น — แต่ตรวจว่าเป็น established character voice หรือ residue |
| ประเมินผู้หญิงในฉากด้วยค่า attractiveness | FEMALE_ASSESSMENT | → GENDER_LOCK_BLOCKED ทันที — นางเอกไม่ประเมินผู้หญิงด้วยค่า attractiveness แบบผู้ชาย |

### Voiceprint ที่ควรสร้างใน Pass 1 (เพิ่มเติมจาก PronounLock)

```
INNER_VOICE_PROFILE:
ตัวละคร: [ชื่อนางเอก]
ตรรกะการตัดสินใจ: [เน้นอะไร — รอดก่อน / ยุติธรรม / ปกป้องคน / พิสูจน์ตัวเอง / อื่น]
วิธีรับมือกับการถูกดูถูก: [เก็บไว้แล้วพลิก / โต้กลับทันที / เดินออก / อื่น]
วิธีมองผู้มีอำนาจเหนือกว่า: [ประเมิน / ระวัง / ท้าทาย / ใช้ประโยชน์ / อื่น]
สิ่งที่นางเอก "ไม่คิดถึง" (ห้าม): [เช่น ไม่คิดแบบ conquest ถ้าไม่ใช่ตัวละครแบบนั้น]
```

### คำถาม INNER_VOICE_REMAP (ตรวจทุก internal monologue)

```

□ มี pattern จากตารางข้างต้นที่ยังค้างอยู่หรือเปล่า?
```
