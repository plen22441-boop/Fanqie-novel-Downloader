แนะนำ วิธีที่ 1 — Bookmarklet (ไม่ต้องลง extension)

  1. กดปุ่ม "เพิ่ม Bookmarklet" ด้านล่างค้างไว้แล้วเลือก "เปิดในแท็บใหม่" หรือ Copy link
  2. บันทึก link นั้นเป็น Bookmark (ชื่อ โหลดนิยาย)
  3. เปิดหน้า boluomao1.com/read/… หรือ /book/… แล้วกด Bookmark นั้น
  4. กด 1. สแกนสารบัญ → 2. เริ่มโหลด → ZIP

Tampermonkey วิธีที่ 2 — Kiwi Browser (Android)

  1. ดาวน์โหลด Kiwi Browser จาก Play Store
  2. ใน Kiwi กด เมนู → Extensions → เปิดใช้ Extensions
  3. ค้นหา Tampermonkey ใน Chrome Web Store แล้วติดตั้ง
  4. กดปุ่มด้านล่างเพื่อติดตั้งสคริปต์
⬇️ ติดตั้งสคริปต์ (Tampermonkey)
💡 ถ้ากดแล้วไม่ขึ้นหน้า Install ให้คัดลอก URL ไปเปิดใน Kiwi Browser ที่ติดตั้ง Tampermonkey ไว้แล้ว
