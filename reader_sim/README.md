# จำลองนักอ่าน My Novel 100 คน

ใช้หลัง QC หนังสือเสร็จ เพื่อประเมินก่อนลงเว็บว่านักอ่าน 100 คนจะ:

- **ผ่าน** กี่ % (อ่านเลย 3 ตอนแรก และให้ ≥ 3 ดาว)
- **ชอบ** กี่ % (≥ 4 ดาว) และ **ดาวเฉลี่ย** + การกระจาย 1–5 ดาว
- **เลิกอ่าน** ตอนไหน (กราฟคนที่ยังอ่านอยู่ในแต่ละตอน) และเพราะอะไร
- **เพิ่มเข้าชั้น** กี่ % และ **ซื้อเหรียญ** หลังตอนฟรีกี่ %
- ผลแยกตาม 9 กลุ่มนักอ่าน (โรแมนซ์ปัจจุบัน, จีนโบราณ/ทะลุมิติ, วาย, เซียน, ระบบ/เกิดใหม่,
  นักอ่านนิยายแปลตัวยง, ขาจร, สายรีวิว, ยูริ) พร้อมช่วงความไม่แน่นอน 90% และเกรด S–D

## ทำงานยังไง

1. ผู้ประเมิน (Claude) อ่านเรื่องจริงแล้วให้คะแนน 11 มิติพร้อมหลักฐานเลขตอนใน `book_profile.json`
2. นักอ่านจำลองแต่ละคนมีแนวที่ชอบ/เลี่ยง, พล็อตที่ชอบ/เกลียด, น้ำหนักแต่ละมิติ, ความอดทน,
   ความโหด และพฤติกรรมการจ่ายเงินไม่เหมือนกัน — คำนวณว่าคนนั้นจะอ่านถึงไหนและให้กี่ดาว
3. สุ่มซ้ำ 300 รอบเพื่อหาช่วง 90% ของตัวเลขหลัก

```bash
python simulate_readers.py --vocab                                   # ดูคีย์ที่ใช้ได้
python simulate_readers.py reader_sim/examples/book_profile.example.json
python simulate_readers.py reports/เรื่อง/book_profile.json --comments reports/เรื่อง/comments.json --out reports/เรื่อง
```

ไม่ต้องติดตั้งอะไรเพิ่ม (ใช้แค่ Python มาตรฐาน)

> ตัวเลขเป็นการจำลองจากสมมติฐาน ไม่ใช่ผลสำรวจจริง สัดส่วนกลุ่มนักอ่านเป็นค่าตั้งต้นที่ควรปรับ
> ด้วยข้อมูลจริงของเรื่องที่ลงไปแล้ว (ดู `calibration.md`)
